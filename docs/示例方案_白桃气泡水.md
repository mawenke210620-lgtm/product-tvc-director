## 创意方向候选

1. **「三点钟的一口气」**——把下午三点拍成一个可被看见的“呼吸节点”：环境声先降到最低，开瓶声与气泡上升成为全片唯一的“事件”，产品在最后完整出现，情绪落点是“她重新开始”。
2. **「不需要理由的甜」**（表述需谨慎，避开“甜”的事实宣称，改为“不需要理由的休息”）——用一组“她拒绝了什么”的快切（拒绝加班、拒绝解释、拒绝负担）反打出一个“她接受了什么”，产品作为唯一被接受的对象出现。
3. **「气泡上升的三十秒」**——以气泡为视觉主角，从瓶底第一颗气泡升起到满瓶细密气泡的微距过程贯穿全片，人物只作为光线与手的局部出现，产品与物理美感成为主角，走极致产品驱动路线，适配品牌长期视觉资产。

## 主卖点与辅助卖点

**主打（核心）：「三点钟的一口气」——下午三点，她停下来，开瓶，气泡升起，深吸一口气，然后重新开始。**

选择理由：

1. **唯一不被事实缺口卡住的卖点。** 场景由资料指定，动作由品类物理基础支撑；不触碰配方、甜味、果汁、包装任何空白区，创意可以完整落地而不产生虚假宣称。
2. **差异化的位置在“动作”，不在“成分”。** 竞品两条路径（讲替代爽感 / 讲生活方式）里，“0 糖 0 脂”已被讲成通用语言；而“用一个极短、可被模仿的身体动作来定义休息”尚未被占位，且天然适合社交平台二次演绎，具备长期资产属性。
3. **它是情绪价值的唯一合法载体。** “不需要克制”不能被说出来，只能被看见——观众看到的不是她忍住了什么，而是她按下开瓶键的那一下。核心卖点承担表达，情绪价值负责被感受，两者不冲突。
4. **天然指向视觉高潮。** 气泡上升是本品类最诚实、最有说服力的物理美感，全片可以收束于产品最完整的呈现，符合“最终高潮是产品本身”的原则。

**辅助卖点（按使用顺序）：**

| 顺序 | 辅助卖点 | 承担任务 | 表达边界 |
|---|---|---|---|
| 1 | 白桃香气先于味道抵达 | 建立感官期待，给“停下来”一个理由 | 只用光影、微距、呼吸表演暗示，不出文案、不做“真果汁/自然甜”外推 |

| 4 | 即饮、开瓶即用 | 支撑“休息的启动成本最低” | 包装形态按占位处理，不呈现可读标签 |

# 第04步 · 推荐三种视觉风格

## 风格一｜电影叙事感 · 日常切片

**视觉关键词**：真实、未修饰的瞬间、手持微晃、自然窗光、克制的表演、生活质感、恰好被看见

**色彩体系**：低饱和的日常底色，包括灰白、浅木、米色、雾蓝等办公与居家环境的自然色。白桃粉只作为画面中唯一的暖色事件出现，即产品本身与它投射的一小片粉色反光。整体不做统一调色滤镜，保留肤色与环境的真实偏差，避免广告感的“高级灰”。

**材质与美术**：美术核心是“真实使用过的桌面”，包括摊开的笔记本、凉了半杯的水、手机屏幕朝下、一支笔帽没盖的笔。产品以占位形态出现在这个真实的场景里。桌面材质选哑光木或浅色岩板，避免高反光。全片不出现可读的品牌文字、营养标签或任何认证标识。

**光影设计**：主光是下午三点左右的斜射自然窗光，从画面左后方 45° 切入，硬中带柔，在桌面拉出长而清晰的窗框影。产品处于侧逆光位，让瓶（罐）体边缘形成一道亮线，气泡在逆光下才可见。补光极低，暗部保留细节而不提亮，让画面有真实的明暗落差。

**摄影语言**：以中近景与特写为主，35—50mm 等效焦段，浅景深但不极端虚化。全片有一个明确的手持段落（她停手、看窗外），到开瓶瞬间切为固定机位，形成“晃—静”的节奏对比。微距气泡镜头用 90mm 微距、固定机位、低速升格。不做炫技运镜，镜头运动只有“她视线转移”和“手伸向产品”两条动机线。

**叙事方式**：线性、单场景、无台词、无旁白。一个人，一个下午三点的断电时刻，一个开瓶动作，一口气。结构为：钝（持续工作）→ 停（视线离开）→ 事件（开瓶与气泡）→ 松（吸气、肩线放下）→ 产品完整呈现。不解释她为什么累，不展示她的身份标签，只给动作。

**如何突出产品**：产品不是被“介绍”的，而是被“需要”的。它出现在她伸手可及的位置，是整个停顿动作的触发点与唯一道具。最后一镜从她的放松状态切回产品本体，逆光立姿、气泡仍在上升，产品获得全片唯一一次完整的独立镜头。

**AI制作难点与风险**：
- 真人表演的微表情与肩线放松是 AI 视频当前最不稳定的部分，闭眼吸气、肩线落下这类细微动作需多次生成筛选或后期修补。
- 手持微晃与自然窗光的“不完美感”容易被 AI 生成成过度平滑的假真实，需在提示词中明确 handheld slight shake、natural imperfect window light。
- 产品为占位形态，开瓶动作与瓶（罐）体结构的一致性需逐镜控制，避免同一片中包装形态漂移。
- 桌面杂物的空间逻辑（笔、杯、手机的位置关系）在多镜头间易错乱，需固定场景参考图。

## 风格二｜高级极简 · 静物仪式

**视觉关键词**：留白、几何、静止、单色场、材质对比、精确、呼吸感、近乎无叙事

**色彩体系**：极窄色域。主色为暖白与浅砂（背景与台面），产品占位色为白桃粉，作为画面中唯一饱和色块。辅以一处极淡的灰绿或灰蓝（如一片叶、一块布），提供冷暖对照。全片不超过三个色相，几乎不使用渐变，靠材质本身的明度差构建层次。

**材质与美术**：美术是“被精心安排过的空”。一块哑光石材台面、一面有细微肌理的墙面、一件极简器皿。产品立于画面黄金分割位或正中，形态简洁。全片道具不超过三件，且每一件都有明确的材质对比关系（哑光石 × 透明瓶体 × 金属开瓶器的一角）。不出现人物，或最多出现一只手的手部入画。

**光影设计**：单一光源的硬光造型，侧光或顶侧光，制造清晰、边缘锐利的产品投影。投影本身是画面的构图元素，占据大面积留白。背景光极低，形成深色渐变或纯色场。气泡在硬侧光下呈现为高对比的亮点，是画面中唯一的“动态纹理”。

**摄影语言**：全部固定机位，三脚架级稳定性，无手持。焦段偏长（85—100mm 等效），压缩空间、消除透视夸张。以极慢的推轨（几乎察觉不到）或纯静止为主。微距镜头占比高，气泡、瓶壁凝露、液面波动均为微距特写。镜头之间以“同一位置、不同时间”的静态构图形成节奏，类似静物摄影组照。

**叙事方式**：非叙事，情绪来自“注视的时长”。结构为：空场（产品未入画或仅局部）→ 产品完整入画 → 微距细节（气泡、凝露）→ 开瓶或倒液的单一动作 → 产品回到完整静止。全片可无人物、无台词，声音设计承担几乎全部情绪（极轻的环境底噪、气泡声、一次开瓶声）。

**如何突出产品**：产品是全片唯一的主角与唯一运动源。留白把所有注意力强制导向产品本体，微距把“气泡”这一品类最诚实的物理美感放大到画面尺度。产品在最后一镜以最完整、最精确的构图呈现，符合“视觉高潮是产品本身”的原则。

**AI制作难点与风险**：
- 极简构图对产品形态精度要求最高，占位包装的任何比例、轮廓错误在留白画面中会被无限放大，必须在客户提供设计稿后重做或实拍替换。
- 硬光投影的物理准确性（投影角度、软硬、与光源一致性）AI 易出错，需逐帧检查或后期合成投影。
- 微距气泡的生成质量与连续性（气泡不重复、不瞬移）是主要风险。
- 全片静止镜头多，AI 视频的“静止”常带有不可控的呼吸抖动，需后期稳定或改用 AI 图像 + 后期运镜。

## 风格三｜自然沉浸 · 白桃果园与气泡之间

**视觉关键词**：自然环境的光、果树、叶隙光斑、露水、柔软的有机形态、感官放大、微距与广角的交替、气味可被看见

**色彩体系**：自然主义色域。以白桃的粉、桃叶的绿、树干的褐、自然光的暖白为主。粉色不只有一种，从果皮的浅粉到果肉的暖粉，形成同色系层次。绿色作为粉色的对照色，比例克制。整体明度偏高、通透，但不使用广告式的高饱和。

**材质与美术**：两个空间并置：自然环境（桃园、枝叶、晨光、露水、果皮绒毛）与产品空间（透明瓶体、气泡、凝露）。两者的连接靠“材质呼应”——果皮的绒毛对应瓶壁的凝露，果肉的粉色对应产品占位色，叶隙光斑对应气泡的高光。不出现可读标签。真实果实仅作为氛围元素，不构成“含真实果汁”的暗示，需在合规上确认画面不产生原料宣称误读。

**光影设计**：以自然光逻辑为主，逆光与侧逆光为主光位，叶隙形成移动的光斑（dappled light）。产品在自然光下呈现通透感，气泡在逆光中成串发亮。全片有一个明确的“光的变化”节点：从树荫下的斑驳光到产品被一束完整的光照亮的过渡，作为情绪转折。

**摄影语言**：广角与微距的强对比。广角用于环境（树冠、枝叶、光斑），微距用于感官细节（果皮绒毛、凝露、气泡上升、液面）。使用浅景深与自然晃动（轻微风吹感）结合，镜头运动模拟“目光游移”而非机械运镜。升格用于气泡与光斑，正常速度用于环境。

**叙事方式**：弱叙事、感官驱动。没有完整的人物故事线，以“感官的接近”为结构：先是环境（光、叶、风）→ 然后是果实与气味的暗示（微距、绒毛、露水）→ 再过渡到产品（气泡、凝露、开瓶）→ 最后是产品在自然光中的完整呈现。可插入极短的人物感官反应（闭眼、吸气），但不承载剧情。

**如何突出产品**：把“白桃香气先于味道抵达”这一感官钩子视觉化——观众先看到桃子、光、露水，再看到产品，让产品成为感官期待的落点，而非起点。气泡的微距与升格构成全片视觉高潮，产品在自然光中完整呈现收尾。

**AI制作难点与风险**：
- 真实果实与产品并置可能产生“含果汁/原料”的暗示，存在合规风险，需客户与法务确认，必要时以抽象色块或纯光影替代果实实拍。
- dappled light（叶隙光斑）在 AI 视频中容易抖动、闪烁、不连续，需逐镜控制或后期叠加。
- 自然环境与微距场景的色调统一难度高，多镜头间易出现色温漂移。
- 广角环境镜头中的植物形态 AI 易生成不合理结构（叶片连接、枝条走向），需筛选。
- 若插入人物感官反应镜头，同样面临真人微表情的生成风险。

## 推荐

**推荐风格一｜电影叙事感 · 日常切片。**

理由：

1. **与核心卖点的结构完全对齐。** 核心卖点是“三点钟的一口气”——一个有前因（工作）、有事件（开瓶）、有结果（放松）的动作序列。这一结构本质上是叙事的，只有电影叙事感能把它完整承载；高级极简会抽掉“前因”，自然沉浸会抽掉“她”，两者都会让核心卖点失去落点。
2. **最贴合品牌方目标与品牌资产诉求。** 客户要的是人群共鸣与长期资产，不是促销。一个可被模仿的身体动作（停手、开瓶、吸气）需要真实的人与真实的场景才能成立，也才具备社交二次演绎的可能。极简与自然沉浸都更接近“产品美学片”，共鸣弱、可模仿性低。
3. **对信息缺口的暴露风险最低。** 本片包装形态、配方、认证全部未知。叙事风格的注意力分布在人物、动作、环境与产品之间，占位包装不会成为唯一焦点；而高级极简把产品置于留白正中，任何形态误差都会被放大，返工风险最高。
4. **AI 制作风险最可控且可修补。** 真人微表情虽是难点，但叙事片容许“不完美”的存在，可通过多镜筛选与剪辑规避；极简片要求产品精确与投影精确，自然沉浸片存在合规与光斑连续性问题，两者的容错空间都更小。
5. **“0 糖 0 脂”的落版位置在叙事风格中最自然。** 情绪闭合之后再给出理性信息，符合“先感受、后确认”的传播逻辑；在极简与自然沉浸中，落版信息容易显得割裂或像产品说明。

**风险提示**：风格一的成片质量高度依赖两件事——客户提供的包装设计稿或实拍素材（决定产品镜头的可信度），以及真人表演镜头的 AI 生成稳定性（决定情绪是否成立）。若客户包装素材延迟，建议先用占位版本完成分镜与节奏验证，产品特写镜头预留实拍替换位。

# 第05步 · 三套差异化创意提案

## 提案一｜《三点，为自己按一次暂停》

**创意名称**：三点，为自己按一次暂停

**核心命题**：给都市年轻女性一瓶白桃气泡水，把下午三点从“熬过去”变成“为自己停下来的一口气”。

**创意类型**：情绪共鸣（故事叙事型）

**适用人群**：25-35岁都市职场女性，有下午疲惫感、对成分有基础认知、渴望“被允许休息”的人。

**核心卖点表达**：
- 主打：三点钟的一口气——开瓶、气泡升起、深吸一口气、重新开始，用一个身体动作定义“休息”。
- 辅助：白桃香气用光影与呼吸表演暗示（不出文案）；气泡作为开瓶时刻的声音与视觉事件；0糖0脂只出现在落版文字，不口头宣称。

**故事结构**：情绪共鸣
- 0-5s：下午三点的办公室切片——键盘声、消息弹窗、日光偏斜，一切在加速。
- 5-12s：她的手指悬在键盘上，停了一拍。视线离开屏幕，落向桌角那瓶占位产品。
- 12-22s：开瓶声切开环境音，世界短暂静默；微距气泡上升，她闭眼深吸一口气——这一口气是全片的呼吸节点。
- 22-30s：睁眼，光变了，气泡水中透出的桃色光映在她脸上。落版：主文案+「0糖 0脂」。

**参考影片**：OPPO《夜成都》的都市切片质感；三得利「伊右衛門」广告中“日常动作仪式化”的节奏；A24《The Bear》厨房戏的音效密度。

**情绪曲线**：紧绷（0-5）→ 一拍的迟疑（5-12）→ 释放·静默（12-18）→ 回归但更轻盈（18-30）。峰值在开瓶瞬间。

**视觉高潮**：开瓶声后1.5秒的世界静默 + 微距气泡列队上升 + 她闭眼的侧脸特写，三线同时收束于产品。

**记忆点**：“那一口气”——开瓶后闭眼深吸一口气的动作，可被用户模仿、可成为社交挑战动作。

**主要开头**：声音先行——键盘敲击、消息提示音、会议提醒声以越来越快的节奏堆叠，画面切入她微微皱眉的侧脸。

**备选开头一**：光影先行——下午三点斜阳切入百叶窗，光斑缓慢移动，停在桌面那瓶气泡水的桃色瓶身上。

**备选开头二**：动作先行——特写一只手快速翻动文件/滑动屏幕，节奏极快，突然所有动作静止。

**产品露出策略**：前2/3产品作为“被注意到的物体”存在于景深内；开瓶时刻是唯一全画幅呈现；落版给完整产品占位（包装待确认，画面以光斑/桃色液体暗示，不呈现可读标签）。

**音乐与声音方向**：前段无音乐，只有密集环境音（键盘、消息、日光灯嗡鸣）；开瓶“呲”声作为音效事件，随后进入极简钢琴单音+气泡微响；结尾一个轻盈的合成 pad 收束。开瓶声必须实录质感（音效库高质量采样），不可用AI生成音效替代。

**广告语**：三点，为自己按一次暂停。（备选：下午三点的这一口气，是白桃味的。）

**AI制作方式与风险**：

# 第06/07步 · 导演深化 · 产品视觉圣经

## 导演深化

- **故事是否成立**：成立。30秒内“压迫—暂停—回归”三段结构清晰，核心事件（开瓶）位于2/3处，符合情绪峰值位。调整：前段“加速”不能只靠声音堆叠，画面必须有可见的节奏递进（光斑移动、消息弹窗频率、手指动作频率三层同步加速），否则5-12s的“停顿”无落差。
- **人物为何在此**：她是“下午三点疲惫感”的具象载体，不是角色而是状态。结论：全片人物只保留三种镜头——悬停的手、侧脸微皱眉、闭眼侧逆光剪影。不给她完整正脸对话感镜头，降低AI人物崩坏风险，同时保持“每个人都是她”的代入感。
- **产品为何进入故事**：产品是“暂停的许可证”，物理上以桌角静物身份在前2/3潜伏，心理上在开瓶声一刻成为唯一主角。结论：0-12s产品存在但不可读（景深虚焦+桃色色块暗示），12s后才是唯一一次全画幅。禁止中途任何半清晰露瓶。
- **情绪如何变化**：紧绷（堆叠感逐层加密）→ 一拍迟疑（音画同步骤降速）→ 释放静默（开瓶声断崖，1.5秒全静默）→ 轻盈回归（提示音变慢变轻作为余味）。调整：静默段不可完全无声，保留极低电平的气泡微响作“呼吸底噪”，否则1.5秒真空会让观众误判为播放故障。
- **视觉高潮在哪**：开瓶后三线收束——微距气泡列队上升、她闭眼侧逆光剪影、桃色光映面，同框收束于产品。位置约12-16s。
- **最值得记住的镜头**：“那一口气”——闭眼深吸的侧逆光剪影，轮廓边缘有瓶身透出的桃色光染。这是可被模仿的社交动作，必须保证轮廓清晰、情绪松弛。
- **产品露出是否自然**：自然。潜伏—登场—落版的三级露出与“被允许休息”的叙事同构。落版占位需真实产品素材或后期替换，AI画面内不出可读标签。
- **信息是否过多**：不多。全片仅一个文案动作（落版），“0糖 0脂”只以落版文字出现，无口播、无字幕宣称。白桃香气靠桃色光通感，不落文字。确认：保持克制，不加“下午三点”屏幕时钟字样以外的任何UI文字（时钟仅作时间符号，非产品宣称）。
- **哪些画面最难生成**：①闭眼深吸的微表情（AI人物高风险）；②微距气泡物理准确性（上升速度、折射）；③斜阳百叶窗光斑的物理准确度；④瓶身桃色光染在脸上的可信打光。
- **哪些镜头需要替代方案**：
  - 闭眼深吸 → 替代为侧逆光剪影+锁骨与肩部起伏表现呼吸，回避面部。
  - 微距气泡 → AI流体生成不稳定，预置实拍高帧率微距素材为A案，AI生成仅作B案补帧。
  - 光斑移动 → 用AI生成静帧+后期数字位移替代AI视频直接生成运动光斑。
  - 开瓶声 → 全实录采样库，不使用AI生成音频（既定原则）。

# 第09/10/11步 · VFX · 全AI制作 · 声音剪辑

## CGI/VFX 七阶段设计

> 对象：本片唯一贯穿的VFX线索——「百叶窗光斑系统」+「弹窗UI层」+「产品微距气泡层」。全程服务于「压抑→停顿→释放」的节奏结构，不做任何炫技性特效。

| 阶段 | 设计内容 |
|---|---|
| **初始状态** | 镜01：光斑为静态条状暖金光带，以约2px/秒的横向位移缓慢漂移，物理上与窗外太阳偏转一致；弹窗层不存在；产品气泡层不存在。全片光斑系统以同一张HDR桌面素材为载体，保证光影方向永不漂移。 |
| **出现与凝聚** | 镜02：弹窗UI层以纯色圆角色块+模糊图标形式出现，从每1.5秒1个递增到每0.4秒1个，色块亮度高于环境0.5档，制造视觉“跳动”。光斑位移速度提升至镜01的4倍。 |
| **核心形态** | 镜05：开瓶音效触发瞬间插入1帧全黑，随后进入微距气泡层——气泡从瓶口垂直上升，直径2–5mm，上升速度由快到慢指数衰减，表面折射率按苏打气泡设定，不做夸张气泡雨。 |
| **运动与变化** | 光斑系统是全片「情绪速度计」：镜01慢→镜02加速→镜03减速→镜04近乎静止→镜07反向柔化（光斑边缘羽化、扩散为大面积柔光）→镜08转为产品背光的呼吸光晕。所有速度变化通过后期位移曲线（缓入缓出贝塞尔）控制，不用AI视频直接生成光斑运动。 |
| **作用与互动** | 镜02光斑扫过杯沿与文件时产生正确遮挡投影；镜02B光斑边缘扫过桃色虚焦色块（产品潜伏提示）；镜07桃色光晕反向映射到人物面部（腮部、下颌缘），完成「产品作用于人」的光学暗示；镜08产品瓶身标签反光随光晕呼吸同步。 |
| **范围与强度** | 光斑系统：始终限制在桌面与人物侧脸，不污染背景墙；强度峰值在镜02（对比+1档），谷值在镜04。气泡层：仅镜05，数量≤15个可视气泡。面部映射：桃色不超过面部的30%区域，饱和度控制在主色板的60%，避免「滤镜感」。 |
| **结束方式** | 镜08落版：所有运动元素归零——光晕呼吸幅度收敛至±3%曝光、周期4秒，与片尾音效尾音对齐；气泡不延续；黑场前保留0.5秒静态完整产品帧，作为记忆锚定帧。 |

**物理约束**：光斑位移方向全片一致（左→右），速度曲线连续无跳变；气泡受浮力与表面张力真实尺度，不做CG弹性变形；所有投影遮挡与桌面几何一致。
**产品约束**：镜01–04产品保持「虚焦桃色色块，不可读」状态；镜05仅微距气泡，不出现标签文字；镜08为全片唯一可读产品展示，标签、字样按【资料】实际内容合成，资料未提供处标注「待确认」，禁止AI生成替代文字。
**视觉约束**：全片统一暖金→桃色双色温体系；光斑不闪烁；VFX层均基于AI静帧合成，不使用AI视频直接生成光影运动层；负向约束统一：no readable text, no logo (except final pack shot), no flicker, no impossible light direction, no exaggerated particles。

## 全AI制作流程

### 按镜头的流程选型

| 镜号 | 流程 | 理由 |
|---|---|---|
| 01 | AI图像 → 后期数字推轨 | 光斑位移必须精确可控，AI视频光斑漂移不可靠 |
| 02 | AI图像×3 → 后期硬切+弹窗UI合成 | 加速节奏靠剪辑实现，AI只供子镜头静帧 |
| 03 | AI视频（低动态手部）+AI图像备选 | 悬停微动作幅度小，AI视频稳定；备选静帧+缓移 |
| 04 | AI图像 → 后期缓推+分层虚焦 | 「看向」的表演依赖静帧人物侧脸质量 |
| 05 | AI图像微距 + 气泡为**粒子三维辅助合成**（或高质量AI视频+逐帧校验） | 气泡物理精度要求高，三维辅助更可控 |
| 06 | AI视频（侧逆光剪影，闭眼+呼吸） | 动态核心镜头，人物表演幅度适中，AI视频可胜任；眉眼细节被剪影遮蔽，规避AI面部崩坏 |
| 07 | AI图像×2–3 → 柔化叠化 + 桃色映射VFX | 松弛段落以静帧叠化为主，降低连续性风险 |
| 08 | AI产品图（需高质量静帧或三维渲染贴图合成）→ 光晕呼吸后期 | 落版产品必须最高精度，建议实拍质感AI图或三维辅助产品渲染 |

### 工具匹配逻辑
- **人物静帧（镜01/02/04/07）**：高写实人像模型（如Midjourney/可商用写实人像管线），固定同角色：通过同一参考图+固定seed范围+统一服装发色描述词锁定人物一致性。
- **人物动态（镜03/06）**：图生视频工具（首帧用上文静帧），运动提示词限定「minimal movement」。
- **产品（镜08）**：优先产品三维辅助——以【资料】产品图建简易模型/或AI多角度产品图+透视校准；标签文字为后期平面合成，禁AI直接生成文字。资料仅有单角度图时，其他角度标注「待确认产品多角度素材」。
- **合成层**：Nuke/AE级2D合成：光斑位移、弹窗UI、气泡粒子、光晕呼吸。
- **一致性管线**：LUT+统一色板（暖金#C89660系 / 桃色#F2A6A0系）、统一胶片颗粒层、统一暗角，全片后期统一施加。

### 关键帧工作流
1. 生成人物基准静帧（镜01），确认为全片「母帧」。
2. 以母帧为参考生成镜02/04/07静帧（同服装、同桌面、同光向）。
3. 母帧图生视频产出镜03/06动态素材。
4. 产品素材独立生成/建模，仅镜05/08入画。
5. 后期按分镜组装，逐镜头叠加光斑/UI/气泡合成层。
6. 统一调色→颗粒→输出。

### 镜头连续性检查清单
- [ ] 人物：发型、服装、坐姿方向、手表/袖口细节全片一致（镜01↔02↔04↔06↔07）
- [ ] 光向：太阳位置（左后→右前）全片一致，光斑方向不翻转
- [ ] 桌面道具：水杯、文件位置跨镜不跳变（同机位参照静帧比对）
- [ ] 产品：桃色色块的色相/明度在镜01–04保持一致；镜05瓶口形态与镜08瓶身一致
- [ ] 时间逻辑：光斑位移量与「下午三点」设定匹配，不出现光向回跳
- [ ] 色彩：双色温体系贯穿，镜06为剪影反差峰值，镜08回到平衡
- [ ] AI手部：逐帧检查指节数量与比例，崩坏帧用剪影化或剪辑规避

### 分段声音设计

| 段落 | 音乐 | 环境音 | 动作音效 | 旁白 | 静音留白 | 声画同步 |
|---|---|---|---|---|---|---|
| 镜01 (0–3s) | 无，仅隐性100BPM节拍脉冲（低频，-18dB） | 键盘声、远处电话、空调低频 | 键盘敲击按节拍量化 | 无 | 无 | 敲击声与光斑位移形成同速基准 |
| 镜02 (3–7s) | 无旋律，节拍脉冲密度提升至2× | 空调渐强，环境声像收窄 | 通知提示音频率递增（音高逐次+半音制造烦躁感）、键盘加密 | 无 | 无 | 三子镜头硬切点与提示音一一对齐，形成音画双重加速 |
| 镜03 (7–10s) | 节拍脉冲骤停 | 环境音-6dB，声场变「空」 | 最后一次键盘单击，随后无动作音 | 无 | 10.5s起0.5秒近全静，仅存极轻呼吸声 | 悬停瞬间声学「刹车」与画面减速同步 |
| 镜04 (10–12s) | 无 | 屏息前奏：空调声滤波至近似消失 | 无 | 无 | 持续低密度静默，保留房间底噪-30dB | 极缓推与声压同步衰减 |

| 镜06 (14.5–18s) | 单一持续音进入：低频钢琴长音+微量气泡声铺底 | 近无 | 吞咽/呼气声（拟音，轻于环境气泡声） | 无 | 无 | 肩线起伏的呼吸节奏与长音包络同步（呼吸频率约10次/分） |

### 剪辑策略说明
- **快切**：仅镜02内部使用（1.6s→1.3s→1.1s三段硬切），切点与提示音对齐，形成「剪辑即心跳加速」的效果；切点不用叠化，保持锋利。
- **慢节奏**：镜03–04连续5秒无一次剪辑（镜头内缓移），与镜02形成最大密度落差。
- **节奏递进**：全片剪辑密度曲线为「低→峰值→归零→低」，镜05黑帧+开瓶声是声画双重的「重置点」，后半段所有声音元素（提示音、环境）以慢速回放形态回归，暗示「时间被松开」。
- **动静对比**：镜02（动·声满）↔镜03–04（静·声空）；镜05黑帧（绝对静止）↔开瓶声（最大瞬态），全片唯一一次「黑中爆声」。
- **匹配剪辑**：①镜02→03动作匹配（最后一击→悬停手指，帧级对位）；②镜04→05视向匹配（视线落向瓶身→微距瓶口特写，同轴线）；③镜06→07呼吸匹配（剪影肩线起伏→睁眼瞬间与长音包络上升帧对齐）。

### 交付备注
- 全片响度基准：-14 LUFS，动态保留：开瓶声峰值可高于环境基准12dB，不压缩至扁平。
- 旁白文案中所有产品信息（0糖0脂等）须与【资料】核对，未确认项标注「待确认」，不进入成片口播。
